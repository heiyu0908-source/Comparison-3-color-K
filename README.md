# XAUUSD 三色 K、信号账户与 ATWT 基金对比

当前局域网报告的完整静态网页副本，入口为 `index.html`。

## 使用

直接用浏览器打开 `index.html`，或将仓库根目录部署到静态网页服务器。

在仓库根目录运行以下命令，以 **48173** 端口启动网页服务（需要 Python 3）：

```bash
python3 -m http.server 48173 --bind 0.0.0.0
```

本机访问：<http://localhost:48173/>。

当前服务器访问：<http://43.133.219.166:48173/>。

公网访问需要在服务器防火墙和云安全组中放行 TCP 48173。使用 UFW 的服务器可执行：

```bash
sudo ufw allow 48173/tcp comment 'Comparison-3-color-K'
```

网页包含账户对比、10 万美元本金模拟、日期筛选、月末净值明细和 CSV 导出。数据来源、截止日期及口径差异详见页面说明。

无需构建；页面样式、脚本和报告数据均包含在 HTML 文件中。
